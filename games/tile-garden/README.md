# Tile Garden | WebLorosae Games

Original Mahjong solitaire browser-game prototype, stored separately from the main WebLorosae website.

## Try it locally
Open `index.html` in a browser. On GitHub, choose **Download raw file** to save it. No dependencies or build process are required.

## Current GitHub edition
- 64 tiles in two layers
- Solvable board generation
- Classic levels and daily challenge
- Hint, undo, reshuffle and restart
- Local browser progress saves
- Responsive touchscreen interface

This is a **lightweight standalone edition** of the game. The earlier downloadable **Tile Garden v0.4** package also contained achievements, optional sounds, custom icons and offline-installation files; those extra files have **not yet been uploaded to this folder**.

## Deployment
No GitHub Pages deployment has been enabled or changed here. Because the parent repository is public, this source code is public. This folder is not linked from the main WebLorosae website.

No third-party graphics, audio or libraries are bundled. Browser play has not been tested on a physical iPhone.
